# Clario 验证边界

- 单进程、单用户运行；调度器需要后端存活，服务重启不保证继续进行中的 Agent 回合。
- L1 分数是启发式学习状态，不是经过标定的概率。讲解、阅读或成功运行代码不能单独作为掌握证据。
- L2 检索评估适用于固定合成语料；不能解释为普遍问答准确率。
- L1 到期复习信息不会自动创建定时任务；练习输出不会自动变成 L1 掌握证据。
- SSE 重连不等于服务重启后恢复执行。
- 基线的 offline 钩子只限制 Node 全局 fetch；路径隔离不等于操作系统权限沙箱。
- 自动工程检查不替代真实模型教学及浏览器人工验收。未执行的检查应记录为未执行。

出现失败时保存运行 ID、复现步骤、日志及实际结果，不通过降低断言或隐藏跳过项改变结论。

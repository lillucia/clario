后续执行：2026-10-04 已完成 [一条受控真实模型流程](results/2026-10-04-live-learning.md)，覆盖下表 A1/A2/A4/A5 的部分能力，25 项数据与 trace 核对通过。合成学习者、显式工具指令和正确答案场景的结果不能替代 A2 的带提示回答、A3 的完整修复回题、A4 的重复归档、A5 的无关召回、A6 的流刷新/取消/代码执行或 A7 的计划验收；这些仍未在真实模型下完整执行。

## Web 人工验收

先执行 `npm run baseline:prepare`，使用输出的路径和启动命令。A1 可在 dummy provider 下验收；A2—A7 需要用户自行配置新环境的真实模型。使用虚构学习者、合成材料和一次性练习文件。

| ID | 操作 | 应观察到的行为与证据 |
| --- | --- | --- |
| A1 隔离启动 | 打开 Web，查看设置、会话、工作区和学习者页面，创建一个空会话。 | 页面可用、历史为空或仅含明确标记的基线样例；新文件只落在本次环境。保存启动命令、页面截图及环境路径，排除凭据。 |
| A2 L1 证据 | 提出一个学习目标；让 Agent 只讲解一个概念，再完成一次独立回答和一次带提示回答。 | 目标持久化；讲解不被写成掌握成功；回答对应可追溯证据，提示程度被区分。检查学习者状态/事件记录，不能只看 Agent 自述。 |
| A3 教学入口 | 参照教学测试的“斜面加速度依赖受力分解”合成情境，先建立明确的先修关系和误解记录；要求解决原题，按诊断问题作答并完成修复，再问同类原题。 | 先修诊断等待用户回答；修复后回原题；证据可靠且仍有效时不重复同一诊断。记录工具 trace、实际问答和误解状态。未建立先修关系不能据此判定门控失败。 |
| A4 L2 来源链 | 上传一份包含明确事实的短材料并要求归档，再查询材料里的事实，最后重复归档同一材料。 | 能定位 wiki 页面及原始来源；回答与材料一致；重复归档不产生重复来源。记录来源 ID、页面路径与检索结果。 |
| A5 L3 跨会话 | 在会话甲说明一条独特的虚构信息，结束后创建会话乙并明确询问之前的信息；再问无关问题。 | 相关历史可召回，且有可核查来源；无关问题不注入无关片段。通过 trace/日志区分 L3 召回与模型猜测，不能仅凭回答相同判通过。 |
| A6 Web 流与练习 | 发起含工具调用的任务，流式过程中刷新；再发起另一任务并取消。创建小程序，分别运行成功与失败版本，询问最近一次报错。 | 刷新后恢复执行状态与内容，无重复最终消息；取消后可继续新请求；历史重新打开仍可见。练习记录有命令、输出、退出码，解释引用实际错误。保存 trace、运行 ID 和截图。 |
| A7 站内计划 | 创建不指定外部渠道的近期一次性学习任务，保持服务运行；观察到期提示，接管执行或等待自动执行；另建一个计划槽并跳过。 | 执行进入对应会话并记录结果；同一 occurrence 不重复完成；跳过状态一致。核对任务记录与打卡，不把执行成功解释为用户已掌握。 |

任务失败或结果与预期不符时保留现场，记录失败步骤和实际结果；不要修改样例或放宽断言来制造通过。真实模型存在输出波动，需记录重复次数及每次结果。

```text
输入与关键操作：

已知问题或复现步骤：
```

## 本轮不作为通过条件

- 不验收消息渠道、Electron 打包、CLI 交互和多用户部署。
- 本轮安装跳过 Electron/computer-use 安装脚本；不据此推断桌面运行环境完整。
- offline 仅限制 Node 全局 `fetch`；不验收操作系统级网络封锁或安全沙箱。
- 不要求 L1 自动创建复习任务，也不要求代码运行自动更新掌握度；原版尚未打通这两段。
- 不要求后端退出后定时器继续工作，或服务重启后恢复仍在执行的 Agent 回合。
- 不把 L1 启发式分数当作经过标定的掌握概率，不把固定 L2 语料指标当作普遍问答准确率。
- 真模型凭据未配置时，A2—A7 记“未执行”，不能以 faux provider 或录制演示替代。
